548 diagnósticos entregados a tiempo

En Corpoyarumos, el equipo tenía que preparar un diagnóstico por cada caso y elaborar su plan de fortalecimiento. Cada plan aprobado requería además un diseño curricular.

Automaticé la redacción con Python y la API de OpenAI. El tiempo de preparación bajó de unos 30 a 2 minutos por diagnóstico. Extendí el flujo a los 548 planes asociados y al diseño curricular de cada plan aprobado.
